# Erasers against statics: a review for discrepancies

The review `representations-interchangeable` asks for (the maintainer,
2026-11-21): "it should always be valid to transform equivalent
representations (modulo reflection) in context, including an eraser
node and its static. If this isn't the case, a review for discrepancies
is warranted." Every place the code treats an allocated eraser node
otherwise than the static it stands for, found by a sub-agent's survey
of `spike/` and `glam/`. Checked here against the tree at `a2397c7`: the
kinds, X1's hook and event test, and E1 to E4; E5 to E8 and the list of
places treated alike are the survey's reading, not checked here, E8 its
inference.
Kinds: 6 is `KEraN`, consuming; 7 is `KEraP`, providing, the void
(`spike/net.bend:28-31`, `spike/rules.bend:18-19`).

## The correction first

**X1. Plain demand runs eraser events; eraser nodes arise in sources,
and events may rewrite copied nodes.** Demand's hook for a rewrite that
erases is `Demand.erased`, `KN.ev.settle` (`spike/kdemand.bend:193-194`,
from `kdemand.blend:225`), which runs the event rules on the rewrite's
external ends (`ev.one`, `ev.end`, `spike/knet.bend:790-802`); an event
rule turns a node into an eraser node in its own slot
(`P.renode(..., P.hd(6, 0))`, `P.hd(7, 0)`, `spike/krules.bend:2388-2442`).
The node an event rewrites is any node an erasure now faces at a port
its kind erases by (`ev.is`, `spike/knet.bend:692-693`), so a finished
node a copy has taken is no exception: `copied-nodes-untouched`'s
"no eraser event modifies a marked node" is not built, and the marks
are built for controls alone (`fz.copied`).

The freeze review said otherwise twice, and both are wrong:
`Freeze_2026-11-21.md`'s check of C1 ("Latent: eraser nodes are made
only by the event rules ..., and sources run plain demand") and of B3
("What keeps copied nodes today is that sources run plain demand"),
with the second reviewer's same claims in `FreezeFable_2026-11-21.md`
and `finished-trees-cached`'s context. They are corrected where they
stand. `glam/materialize.bend`'s own note says what holds: "a source
must run no events, fusion or collection near copied nodes", a
restriction plain demand does not keep.

Verdict: a regression first, a source whose copied fan an event makes
linear after a copy took it, its outcome against the linker's; then the
marks (`copied-nodes-untouched`), which the fragment cache needs too.
Whether any ladder sample reaches it is the regression's question; the
gate's differential runs pass today.

## Places the two are treated otherwise

**E1. A whole freeze of a net whose root is static gives a cursor**
(`glam/freeze.bend:375-377`, `:363-366`; the freeze review's B1).
`fz.start` pushes nothing for a static, `n` is 0, and the template is
the lone cursor kept for "nothing finished"; an eraser node at the root
freezes as `[eraser]`. Observable: `--refreeze` loads a template whose
root is an eraser as a static (`KN.load`'s statics pass) and freezes it
back as a cursor, demand then stopping on a need where it found the
void. Verdict: fix; a static root freezes as the eraser. Fixed
2026-11-21: the interface facing a static or an eraser node freezes as
the eraser alone, whole or finished (`fz.cap.q`, `fz.void.in`;
`glam/test_freeze.bend`, `void_root`).

**E2. Positioned demand serves an eraser node as the static only at the
interface** (`glam/position.bend:128-130`; the freeze review's C1).
Elsewhere an eraser node is a value whose tree, `[eraser, hole]`, is
frozen and spliced: the splice makes the eraser static, the crossing
joins the served cursor to it, the host the same as the static's path
(`R.leave` with `P.era()`), at the cost of a placeholder made and freed
and a ring's find; its template fails `SV.copy.ok`. Reachable by X1.
Verdict: fix; an eraser node at any position is the static. Fixed
2026-11-21 (`pd.v`; `glam/test_position.bend`, "const_redex's
variable, a node").

**E3. Freeze counts an eraser node among the nodes read back**
(`fz.mark.hd`, `Fz.n`, `glam/freeze.bend`), a static at the same port
not (it goes to the erasers, `fz.peer.k`). `Fz.n` is a serve's count of
nodes copied (`Mz.m`, the core's `cn.copy`): one more for each eraser
node. Counts only; `static-links-count-as-nodes` asks counts to match.
Verdict: fix; erasers out of `Fz.n`, as `tpl.made` counts them. Fixed
2026-11-21 by reading an eraser node as its static throughout: the walk
enters none (`fz.port.c`), a port facing one writes the eraser a static
writes (`fz.peer.s`, `fz.peer.e`), so both forms freeze alike, in order
and count (`glam/test_freeze.bend`, "const_lvl, a node").

**E4. The collector notes an event for a void node at an auxiliary
input, none for a static void there** (`spike/kstrat.bend:404-417`,
`lw.p2`; its comment: "A static void at an auxiliary input is no event
the walk notes: what its node's event would do is left to demand").
Counts (events, interactions, frees per collection, and so a heap's
growth); outcomes the same. Deliberate when written; against
`static-links-count-as-nodes` as the maintainer has now put the
principle. Verdict: note the event for the static too, or record the
exception in that record; a measurement of the counts it moves first.

**E5** (the survey's). **The loader keeps two erasers facing each other as nodes; the
splice writes nothing for them** (`spike/knet.bend:1222-1259`,
`ld.statics`; `glam/splice_copy.bend`, `sp.node_k`, `sp.link2`). An
eager scan counts the loader's pair; demand reaches neither. Recorded
in `splice-erasers-static`. Verdict: as recorded, until the template's
statics become ends (`cells-freeze.format`), when the pair cannot be
written.

**E6** (the survey's). **Eraser nodes are live nodes in the reported counts**
(`spike/knet.bend:1653-1662`, `reach`; `spike/kernel.bend`,
`live_nodes`). Memory, inherent to holding a node. Verdict: none.

**E7** (the survey's). **A wrong-polarity eraser node** (`KEraN` at the interface, read as
a value by `Demand.wk.root`, which tests kind 7, `spike/kdemand.bend:605`;
`ev.st.b`, `spike/knet.bend:751-752`). Only in an ill-typed net.
Verdict: none.

**E8** (the survey's inference). **The eager scan's order** (`spike/kstrat.bend:29-33`, `scan.peer`):
a pair with an eraser node is pushed from its lower-numbered node, one
with a static from its node. Order only. Verdict: none.
