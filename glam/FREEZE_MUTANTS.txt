# runs scripts/one_law.py --mutants on this file). The counts'
# witnesses: one node of kind 1 (a function, three ports) at base 32, its
# ports' words 0, so that each port faces a node not in the map, a
# cursor; with its port 0's word 3, a static. The links': two such
# nodes, at 32 (index 0) and 68 (index 1), the map hm.fill makes of
# them; 32's ports face 68's port 0, a static and a cursor, 68's face
# 32's port 0 and two cursors. The far ends': the same, but 32's ports
# face 68's port 1 and two statics, so that the last eraser is the last
# index. The root's: one function node at 32 whose ports face the
# interface (word 28, the root), a static and a cursor.
