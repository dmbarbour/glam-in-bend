# Mutations of the spike's code, each a fault a law named should catch
# (scripts/one_law.py; docs/Proving.md, What to claim). Try them after a
# proof or the code it follows changes:
#   python3 -I scripts/one_law.py spike/PROOF.bend LAW --mutants spike/MUTANTS.txt
#
# Raising a copy (the laws raise_*): each mutation breaks what raising
# commutes with, not only what a rule computes. A fault that raising
# still commutes with, such as a guard of >= for >, is for other laws.
# Their proofs, mutated, overflow Bend's checker as it reports the
# mismatch over symbolic words, which catches nothing: each carries a
# witness per law, a small instance its law excludes (scripts/one_law.py).

=== bind_level_offset raise_lvl_eq
a bind's level replaced by the offset: every raised pair of levels meets
--- val.bend
    case PLvl{+n}:
      PLvl{(n + k : U32)}
+++
    case PLvl{+n}:
      PLvl{k}
>>> witness raise_lvl_eq
def witness() -> {V.lvl_eq(V.raise_pay(0, V.PLvl{0}), V.raise_pay(0, V.PLvl{1})) == V.lvl_eq(V.PLvl{0}, V.PLvl{1}) : Bool}:
  {==}

# Reading the heap after a write (the laws rd_*): P.rd and P.wr pass
# straight to the word array; each mutation misroutes a read or a write.

=== wr_next_word rd_wr_same
a write lands on the next word: reading the word written misses it
--- kprim.bend
      H{KM.m_set(w, i, v), a}
+++
      H{KM.m_set(w, (i + 1 : U32), v), a}

=== set_drops_value rd_wr_same
the memory's write stores 0 whatever is written
--- kmem_grow.bend
      MG{Array.set(U32, a, i, v)}
+++
      MG{Array.set(U32, a, i, 0)}

=== rd_other_word rd_wr_same rd_wr_other
a read looks at the word after the one asked for
--- kprim.bend
      rd.fin(KM.m_get(w, i), a)
+++
      rd.fin(KM.m_get(w, (i + 1 : U32)), a)

=== wr_clears_neighbour rd_wr_other
a write also clears the word after it
--- kprim.bend
      H{KM.m_set(w, i, v), a}
+++
      H{KM.m_set(KM.m_set(w, (i + 1 : U32), 0), i, v), a}

=== rd_bumps rd_kept
a read hands the heap back with the word it read cleared
--- kmem_grow.bend
  (MG{a}, v)
+++
  (MG{Array.set(U32, a, 0, 0)}, v)

# A node taken from the free list (the laws node_*): each mutation
# misplaces one of the pop's writes outside the node taken, or the index
# it returns; node_keeps claims nothing of the node's own words, so a
# write inside them is no fault of its. Each is refuted by the proofs, so
# none needs a witness.

=== head_next_word node_keeps node_next
the pop writes the new head one word past the head's word
--- kprim.bend
  (H{KM.m_set(w, at_fh(), next), a}, n)
+++
  (H{KM.m_set(w, (at_fh() + 1 : U32), next), a}, n)

=== head_kept node_next
the pop leaves the head as it was: the same node taken again next
--- kprim.bend
  (H{KM.m_set(w, at_fh(), next), a}, n)
+++
  (H{w, a}, n)

=== payload_past_node node_keeps
a node's payload written into the next node's header, past its own words
--- kprim.bend
  (wr(wr(h, n, hd), (n + node.word(hd) : U32), p), n)
+++
  (wr(wr(h, n, hd), (n + 4 : U32), p), n)

=== index_of_head node_index
the node returned is the head's index times four, not its node's
--- kprim.bend
      alloc.pop(KM.m_get(w, (((fh - 1 : U32) << 2n : U32) + 1 : U32)), ((fh - 1 : U32) << 2n : U32), a)
+++
      alloc.pop(KM.m_get(w, (((fh - 1 : U32) << 2n : U32) + 1 : U32)), (fh << 2n : U32), a)

# Linking and freeing (the laws link_keeps, free_keeps): each mutation
# writes a word the law says is left alone. free_keeps claims nothing of
# the freed node's own words, so a mutation inside that node is no fault
# of its.

=== link_at_header link_keeps

--- kprim.bend

+++
